# 小鯨记忆

给小鯨（DSH 里的伙伴人格）做一套长期记忆系统。核心不是「记得多」，是**记得对**——每条记忆都带来源和把握，会随时间降温而不是被抹掉，而且能看见。

## 项目目标

分三层做，每层可以单独替换：

| 层 | 要解决的问题 | 关键点 |
| --- | --- | --- |
| **行动机制** | 记忆怎么形成、怎么过滤、怎么遗忘与沉淀 | 写入宽、检索严；忘记是降温不是删除；事实键 + 取代，防止记着一个已经过期的对方 |
| **内容机制** | 对话之外的知识怎么进来（Obsidian 经验与读书笔记） | 每篇笔记生成 sidecar 索引（摘要/实体/关键词/标签），检索先走索引再取正文；双链直接建边；**专业知识与私人记忆分库存** |
| **展示机制** | 怎么看见自己的记忆海 | 星图 + 时间轴两个视图；节点大小=权重、颜色=类型、虚线=双链、实线=共现；界面双方都能看、能改 |

起步顺序：先做行动机制的最小闭环（写入 → 开场注入三到五条 → 检索 → 衰减），跑两周验证会不会「记歪」，再动星图。

参考实现：[`Yuuyuko-uu/dsh-fish-memory`](https://github.com/Yuuyuko-uu/dsh-fish-memory) v1.5.8（本目录 `dsh-fish-memory/` 为只读 clone）。
